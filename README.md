# 一起長大｜幼兒家庭陪伴工具箱

這是一個可直接在瀏覽器使用的靜態網站，提供四歲左右幼兒的家庭活動建議、六個月彈性發展方向、家庭觀察工具、公開資源連結，以及 2–5 歲身高與體重百分位參考。

## 隱私與資料邊界

- 網站沒有帳號、伺服器資料庫、分析追蹤或表單提交。
- 成長頁的生日、身高與體重只保存在使用者自己的瀏覽器 `localStorage`。
- 量測日期、性別、百分位結果、圖表狀態與歷史紀錄不保存。
- 清除瀏覽器網站資料後，本機保存的輸入也會消失。

## 使用提醒

內容供家庭陪伴與一般發展觀察參考，不是醫療診斷、心理診斷或治療處方。若家長對孩子的語言、行為、動作或成長狀況有疑慮，請諮詢兒科醫師或合格專業人員。

## 公開內容

- `index.html`：家庭陪伴工具箱
- `growth.html`：身高與體重百分位工具
- `output/pdf/parent_guide.pdf`：家長陪伴手冊
- `output/pdf/child_workbook.pdf`：孩子活動本
